INVITACIÓN BAT MITZVAH HANNA - OPCIÓN GRATUITA

Esta versión está preparada para:
- Publicarse gratis en GitHub Pages.
- Guardar confirmaciones gratis en Google Sheets.
- Compartirse por WhatsApp con un link.

ARCHIVOS
- index.html
- style.css
- script.js
- assets/hanna-portada.jpg
- google-apps-script.txt

IMPORTANTE
Si abrís index.html directamente desde el celular, puede verse sin diseño.
Eso no significa que esté mal. La forma correcta es publicarla en GitHub Pages.

FORMULARIO
La confirmación es solo para la fiesta.
Cantidad permitida: 1 o 2 personas.
Menú: Carne / Vegetariano por cada asistente.
Canciones: hasta 5.
Mensaje: opcional.

PASO 1 - CREAR GOOGLE SHEETS
Crear una planilla con estos encabezados:
Fecha | Nombre | Asistencia | Cantidad | Menú 1 | Menú 2 | Canción 1 | Canción 2 | Canción 3 | Canción 4 | Canción 5 | Mensaje

PASO 2 - CONECTAR APPS SCRIPT
1. En Google Sheets, ir a Extensiones > Apps Script.
2. Borrar lo que aparezca.
3. Pegar el contenido del archivo google-apps-script.txt.
4. Guardar.
5. Ir a Implementar > Nueva implementación.
6. Tipo: Aplicación web.
7. Ejecutar como: Yo.
8. Quién tiene acceso: Cualquier usuario.
9. Implementar.
10. Copiar la URL que termina en /exec.

PASO 3 - PEGAR URL EN EL SITIO
1. Abrir script.js.
2. Buscar:
   const GOOGLE_SCRIPT_URL = '';
3. Pegar la URL entre las comillas.
4. Guardar.

PASO 4 - PUBLICAR EN GITHUB PAGES
1. Crear cuenta en github.com.
2. Crear repositorio: hanna-bat-mitzvah
3. Subir todos estos archivos y la carpeta assets.
4. Ir a Settings > Pages.
5. En Branch elegir main y /root.
6. Guardar.
7. Esperar unos minutos.
8. GitHub dará un link para compartir por WhatsApp.
